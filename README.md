# Under Construction Page 🚀

A clean, modern, and easy-to-use **Under Construction / Coming Soon** web page. Perfect to show visitors that your site is getting built!

---

## 🌐 Live Demo

- 🔗 **Website**: [https://webdeveloperdesigner.github.io/under-construction-page/](https://webdeveloperdesigner.github.io/under-construction-page/)
- 💻 **GitHub Repo**: [https://github.com/webdeveloperdesigner/under-construction-page](https://github.com/webdeveloperdesigner/under-construction-page)

---

## ✨ Features

- **Dark Mode**: Looks great with dark background colors and soft glows.
- **Cool Animations**: Smooth floating illustration and glowing badge.
- **Mobile Friendly**: Works smoothly on phones, tablets, and computers.
- **Simple & Fast**: Built with simple HTML and CSS so it loads instantly.

---

## 🛠️ Built With

- **HTML5** - For page layout
- **CSS3** - For styling, colors, and animations
- **Google Fonts** - Nice fonts (`Inter`, `Sora`, `Outfit`)

---

## 💻 How to Use

1. Download or clone this project.
2. Open `index.html` in your browser.
3. Or run it locally with terminal:

```bash
npx serve .
```
